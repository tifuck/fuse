GET /v1/models

Returns the model IDs available to the authenticated account. Grok models are included only when that account has Grok access.

cURL
curl {{ base_url }}/models \
  -H "Authorization: Bearer $FUSE_API_KEY"
200 application/json
{
  "object": "list",
  "data": [
    { "id": "{{ example_model }}", "object": "model", "owned_by": "fuse" }
  ]
}

POST /v1/chat/completions

Creates a chat completion using the OpenAI Chat Completions request shape.

FieldTypeDescription
modelstring

Required. An ID returned by GET /v1/models.

messagesarray

Required. Conversation messages with role and content.

streamboolean

Optional. Set to true for server-sent events. Defaults to false.

max_tokensinteger

Optional. Maximum generated tokens, capped by Fuse server policy.

temperaturenumber

Optional. Sampling temperature supported by the selected model.

toolsarray

Optional. OpenAI-compatible tool definitions for models that support tool calls.

prompt_cache_keystring

Optional. Sticky conversation id for pooled Grok, ChatGPT, and Z.AI accounts. Reuse it on follow-up turns so Fuse keeps the request on the same subscription and forwards Grok x-grok-conv-id / ChatGPT prompt_cache_key. You can also send the Grok header x-grok-conv-id. If omitted, Fuse hashes the first system message, first user message, tools, user, and model.

cURL · streamed
curl -N {{ base_url }}/chat/completions \
  -H "Authorization: Bearer $FUSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "{{ example_model }}",
    "messages": [
      {"role": "user", "content": "Explain this repository."}
    ],
    "stream": true
  }'

text/event-stream

Server-sent events

data: [DONE]

OpenCode

custom OpenAI-compatible provider

Add Fuse as a custom provider. OpenCode does not dynamically import custom-provider models from /v1/models, so install (or refresh) the catalog with the wizard below. It only edits provider.fuse and replaces the Fuse model list.

Installer

Install with a script

Backs up ~/.config/opencode/opencode.json (or .jsonc) and writes the current Fuse model catalog. If a Fuse API key is already in that file, the installer reuses it and does not prompt or change the key. Re-run anytime to refresh models. Pass --api-key only to set or rotate a key.

curl -fsSL {{ site_url }}/install-opencode.sh | sh

Non-interactivecurl -fsSL {{ site_url }}/install-opencode.sh | sh -s -- --api-key sk-… --yes
