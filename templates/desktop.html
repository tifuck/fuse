Updates

automatic

The desktop app checks this server on launch, downloads new wrapper versions silently, and swaps them in the next time you quit. You never need to reinstall for site changes — chat, models, and settings are always the live site.

No install? Use the PWA

mobile & desktop

The site is an installable app too. In Chrome, Edge, or Brave choose Install app (Safari: Add to Dock, Android: menu → Install app) and it launches full-screen with no address bar — the same zero-maintenance experience without downloading anything.
